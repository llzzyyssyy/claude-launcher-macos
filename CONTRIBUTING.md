# Contributing

Issues and pull requests are welcome.

Before submitting a change:

1. Keep VPN application matching explicit and conservative.
2. Do not add credentials, API keys, cookies, account data, or private network
   configuration to source code or fixtures.
3. Run `./build.sh` and the built-in self-test.
4. Explain any behavior that changes VPN state, region checks, or application
   launch decisions.
